# Trakk

**Proof of progress.**

Trakk is a transparent work log system. Each project has a public record of tasks completed over time — what was done, when, and how long it took. No dashboards, no billing — just a clear trail of work.

## Projects

| Project | Description |
| ------- | ----------- |
| [FOS System Mobile](projects/fos-system-mobile/index.md) | Remittance and member management platform |
| [Project A](projects/project-a/index.md) | Sample web application rebuild |
| [Project B](projects/project-b/index.md) | Sample API maintenance and documentation |

---

To add a new project, create a folder under `docs/projects/` with an `index.md` and monthly log files, then update `mkdocs.yml` navigation.
